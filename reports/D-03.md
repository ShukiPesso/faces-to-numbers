## Deviations / decisions taken in the spec
1. **RouteMap marker links.** F-11 wraps markers in links inside `<svg role="img">`. Children of `role="img"` are presentational, so focusable links inside it are an a11y conflict. The spec makes the marker links a pointer-only shortcut (`tabindex="-1"`, `aria-hidden="true"`, hit area ≥ `--tap-min`). The station list remains the accessible route. `design/route-map.md` (classes for visited/current) does not exist yet; the spec defers to it.
2. **DriveBanner** uses only `Car`. `TriangleAlert` (listed in `icons.md` for DriveBanner too) is not used there, so the banner has a single calm glyph. `TriangleAlert` stays on the ContentWarningGate label.
3. **ReadAloudToggle** keeps a constant visible label (`readAloud.label`) with `aria-pressed`. `readAloud.on` / `readAloud.off` are announced in a hidden status region and are not shown. Fill, weight and the visibly larger page text are the non-color cues.
4. **SilenceMoment** has no restart after it ends. Focus moves to the running panel, not to "stop", so a second tap cannot end it by accident. Only the start and end are announced.
5. **NearbyBanner**: the privacy line is visible in every state. The live region is empty in idle (matches F-12). Failure states are not red.
6. **BottomNav**: "איפה אני" is never marked as the current item. On `/tour?locate=1`, "המסלול" is the current item.
7. **DepthTabs**: the tabpanel (`id="depth-panel"`) is rendered by the page (F-16), not by DepthTabs, because F-08 gives DepthTabs only `value`/`onChange`.
8. **SourceList "publisher"** (CT-SRC-01): there is no publisher field in the schema; the publisher is part of `source.title` in content. The host name is shown in `<bdi dir="ltr">`.
9. **StationCard `total`** comes from `getTour().stationIds.length`, so F-10's props stay `station, visited, current?`.
10. The sketches name the right edge as the start side (as the task asks) and arrows as "points left/right" only to explain mirroring. All layout rules use logical directions.

## Questions / risks / things I noticed outside my scope
1. Conventions §5 names a token `--focus-ring`; it does not exist. D-02 split it into `--color-focus`, `--focus-ring-width`, `--focus-ring-offset`, and the specs use those three.
2. The banner slot (OfflineIndicator/UpdatePrompt) is in normal flow at the top of the page. When a banner appears mid-read it pushes content down. Safari has no scroll anchoring, so the visitor may see a small jump. An alternative is to show UpdatePrompt only on the next route change (an F-12 decision).
3. `design/icons.md` row 16 says the UpdatePrompt button is "לרענון", but `he.ts` has `update.reload` = "לעדכן". The spec uses the key; icons.md is just out of date.
4. `docs/05_DESIGN_BRIEF.md` lists `ShareButton`, the skip link and the sticky bar only implicitly. They are specified here so F-07/F-06/F-15 have no gaps.
