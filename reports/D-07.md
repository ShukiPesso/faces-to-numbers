## Questions / risks / things I noticed outside my scope

1. **Silence countdown conflict (carried over from D-01).** `design/01-principles.md` P5 asks for a static
   "שקט" label with no running digits, but `docs/04_TESTING_STRATEGY.md` CT-SILENCE-01 expects a countdown, and
   `silence.remaining` ("נותרו {seconds} שניות") must keep its placeholder. I left that value as is. The
   orchestrator should decide whether F-tasks render it live or only once.
2. **`nav.whereAmI` / `nearby.button` ("איפה אני")** are first-person singular, which §1.8 would normally
   avoid. I kept them because `content-source/tour.md` (how-to section) quotes the label verbatim; changing
   the UI would make the content wrong. If Shuki wants a plural label, both must change together.
3. **`drive.warning`** uses the generic masculine "מי שנוהג … מי שיושב לידו". Kept because it is word-for-word
   the first safety line in `content-source/tour.md`.
4. **`station.locationUnverified`** now says there are no navigation links. This assumes components hide the
   Waze/Google buttons when the location is unverified (decision #10). If that ever changes, the string must
   change too.
5. The header comment in `src/i18n/he.ts` still says the file is a verbatim copy of the contract; it is no
   longer verbatim in values. I did not edit comments (values only).
