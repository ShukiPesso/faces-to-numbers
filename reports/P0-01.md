## Deviations (all accepted by the orchestrator)
1. **`@vitejs/plugin-react@5` (5.2.0), not latest.** Latest is 6.1.2, which has a hard peer `vite@^8`. 5.2.0 is the newest that supports `vite@5`. All other unpinned packages are at latest.
2. **`tsc -b --noEmit` vs project references.** With `tsconfig.json` → `references: [tsconfig.node.json]`, TS 5.9 refuses `--noEmit`. A composite referenced project gives `TS6310 … may not disable emit`, and a non-composite one gives `TS6306 … must have "composite": true`. So I removed `references`:
   - `tsconfig.json` is a standalone `noEmit: true` project with exactly the step-5 options and include (`src`, `tests`, `scripts`). `typecheck` and `build` keep the §7 script text unchanged and check it.
   - `tsconfig.node.json` is a standalone `noEmit: true` project for the root `*.config.ts` files (`vite`, `vitest`, `playwright`, `tailwind`). ESLint uses it for type-aware linting (`parserOptions.project: ['./tsconfig.json', './tsconfig.node.json']`). **Gap:** `npm run typecheck` does not type-check these root config files. If you want that, the script would need to become e.g. `tsc -b tsconfig.json tsconfig.node.json --noEmit`, which changes the §7 text, so I did not do it.
3. **ESLint ignores `contracts/`** in addition to the listed ignores. The files there are `.ts` but in no tsconfig, so type-aware lint would error on them. They are frozen and copied verbatim into `src/` by P0-02, where they are linted.
4. **No `@eslint/js` recommended config.** It is only a transitive dependency of `eslint`, and importing it would rely on an undeclared package. The config uses only what the task names.
5. **`.js/.mjs/.cjs` files use `tseslint.configs.disableTypeChecked`**, the standard typescript-eslint pattern. This covers `eslint.config.js`, `postcss.config.js` and the future `scripts/check-bundle-size.mjs`, which are in no TS project.
6. `.gitignore` also ignores `*.tsbuildinfo`.
