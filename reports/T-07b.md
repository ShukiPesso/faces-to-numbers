## How fixed elements are handled (style injection, not mask)
`hideFixedElements(page)` runs before every LAYOUT-04 capture:
1. `addStyleTag`: `[data-testid="offline-indicator"], [data-testid="update-prompt"] { visibility: hidden !important }`. These two appear late (service worker ready), so a one-off pass could miss them.
2. `evaluate`: every element whose computed `position` is `fixed` (BottomNav, the station sticky bar below lg) gets `visibility: hidden !important`.
`visibility` keeps layout, so page height and content positions are real. The sticky bar from lg is static, so it stays visible and protected. The existing `[data-volatile]` mask is kept (nothing matches today).
