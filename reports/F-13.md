## Questions / risks / things I noticed outside my scope
1. Home `document.title` is still "פנים למספרים · פנים למספרים". `useDocumentTitle` always appends `app.titleSuffix`, and the existing test `tests/component/layout.test.tsx` ("/ renders the home stub") expects exactly that value, so a direct `document.title = tour.title` would break it. Fixing needs a change to `useDocumentTitle` (or a no-suffix option) and that test, which F-13 does not own.
2. `SectionHeading` renders a `<header>`. Inside the page it is seen as an extra `banner` landmark by Testing Library (breaks the AppLayout landmark tests) and is questionable for a11y. I used a local `<h2>` with the same classes instead. F-07 may want to render a plain wrapper.
3. Visited ids are matched against station `id` or `slug`.
