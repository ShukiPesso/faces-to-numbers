## Questions / risks / things I noticed outside my scope
1. **`border-accent` is two utilities.** The `borderWidth.accent` key (4px) and the existing `colors.accent` key both generate `border-accent`, so the class sets width 4px and red color. This is the start-border look, but a bare `border-accent` also gives a 4px red border on all sides. Renaming the width key (for example `border-w-accent`) would avoid the overlap; I kept `accent` as specified. Please confirm.
2. **`--bottomnav-size` and `--stickybar-size` are not wired.** The D-02b notes say they are set at runtime by layout code (F-06), so I added no Tailwind entries for them.
3. **Fallback `.woff` files are emitted** (8 extra, about 98 KB raw), as the review asked. They are not woff2, so they do not count toward the budget. F-18 is to exclude `*.woff` from precache.
4. **No `fontWeight` default override.** Tailwind's numeric weights (`font-bold`, etc.) remain; the token names are under `extend`.
