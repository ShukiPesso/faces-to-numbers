## Questions / risks / things I noticed outside my scope
1. **Fallback `.woff` files are bundled.** The @fontsource CSS also references a `.woff` fallback for each file, so Vite emits 8 extra `.woff` files (about 98 KB raw in total). They are not `.woff2`, so the F-05 budget is unaffected, but they count toward `dist/` size and, once F-18 adds the PWA precache, toward the 2 MB precache total. Dropping them would need hand-written `@font-face` rules with woff2-only `src`. I did not do that because the task says to import the @fontsource packages.
2. **Spacing has no `0` or `px` key.** The task's spacing map is token-backed only (`--space-1` … `--space-12`), so Tailwind's default `0`, `px` and `0.5`-style spacing keys are gone. Any component that needs `m-0` or `p-px` will need a token or a decision from Architecture.
3. **Other replaced theme groups lose defaults.** Replacing `colors`, `borderRadius` and `boxShadow` removes defaults such as `white`, `black`, `transparent`, `rounded-full`, `shadow-sm`. Components must use the token names only.
4. **`fontWeight` not themed.** The task did not list it, so Tailwind's default weights remain. The `--font-weight-*` tokens are unused by the config; F-06/F-07 may want them under `extend.fontWeight`.
5. **Focus ring on `:focus-visible` only.** It applies to every focusable element through the base layer. Components that set `outline-none` will override it.
6. No `tests/` or `e2e` checks were run because the task does not ask for them.
