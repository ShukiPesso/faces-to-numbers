## What I did
I wrote `scripts/check-bundle-size.mjs`, a dependency-free Node ESM script. It measures the gzip size of JS and CSS, the raw size of woff2 fonts, the precache total and the file count in `dist/`, and compares them with the Architecture §9 budgets (one `BUDGETS` constant). It prints a table and exits 1 on any FAIL or when `dist/` is missing. The pure `evaluate()` function is exported and unit-tested. The precache total is the raw size of the files named by `url:"…"` entries in `dist/sw.js` (the Workbox manifest format); if `sw.js` is missing it uses the total size of `dist/` and says so. Paths that escape `dist/` or are absolute URLs are ignored. `.github/workflows/ci.yml` has the `check` job and the `e2e` job (needs `check`), with concurrency and read-only permissions. It uses no secrets.
