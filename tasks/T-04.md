## Goal
Location is only ever read when the visitor asks, the answer is correct for at / near / far / denied, and navigation links point to exactly the verified coordinates.

## Context
All tests here run on the FIXTURE build (fictional stations test-a/b/c with known coordinates), tag @fixture,
project fixture-chrome. Real stations may still have location null, so real content cannot be used for this.

## Steps
1. E2E-GEO-01: grantGeo(context, FIXTURE_POINTS.atA) → '/#/tour' → click where-am-i → nearby-banner contains the test-a title (compute the expected text from the strings contract 'nearby.at' with {title}) and its link opens '/#/station/test-a'.
2. E2E-GEO-02: nearB → banner says near test-b and contains a distance text (a number followed by מטר or ק״מ).
3. E2E-GEO-03: far → banner shows the 'nearby.none' string.
4. E2E-GEO-04: denyGeo(context) → banner shows the denied string; the station list is still visible and clickable.
5. E2E-GEO-05: spyGeolocation(page) before navigation; visit every fixture route (/, /tour, each station, each person, /about, /sources) and assert getCurrentPosition was called 0 times.
6. E2E-LINK-01: '/#/station/test-a' → nav-waze href equals exactly 'https://waze.com/ul?ll=31.400000,34.500000&navigate=yes' and nav-google href equals 'https://www.google.com/maps/dir/?api=1&destination=31.400000,34.500000'; '/#/station/test-c' → location-unverified visible and no nav-waze / nav-google.
7. Title every test with its ID and '@fixture'.

## Do NOT
