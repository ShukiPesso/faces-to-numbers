## Goal
Before launch, an independent reviewer confirms that every test in the catalog exists, actually tests what it claims, and is stable.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `docs/04_TESTING_STRATEGY.md`
- `tests/`
- `src/`
- `reports/`

## Owns files — you may create or modify ONLY these
- `review/T-11-test-audit.md`
- `reports/T-11.md` (your report)

## Steps
1. Make a table of every ID in docs/04_TESTING_STRATEGY.md §4 (UT-*, CT-*, CI-*, E2E-*, LH-*) → file and test name that implements it, or MISSING. Use grep for the ID in tests/.
2. Run npx vitest run --coverage; record the numbers for src/lib/** and src/components/** against the thresholds.
3. Run the full Playwright suite 3 times (npx playwright test --repeat-each=1, three separate runs); list any test that failed at least once as FLAKY with its error.
4. Mutation spot-check (on a throwaway local branch, never committed): (1) change wazeUrl to swap lat/lng; (2) remove the ContentWarningGate around oct7 in PersonPage; (3) add '!' to one he.ts value; (4) change one word in one person JSON; (5) call getCurrentPosition on mount in useNearbyStation. For each, record which test failed. A mutation that no test catches is a HIGH finding.
5. Grep for test.skip, test.fixme, .only, waitForTimeout and report every hit.
6. Write review/T-11-test-audit.md: summary verdict (READY / NOT READY), the catalog table, coverage, flaky list, mutation table, findings ranked HIGH/MEDIUM/LOW with the task ID that should fix each.

## Do NOT
- Do not fix tests or code yourself — report. Do not commit the mutation branch.
