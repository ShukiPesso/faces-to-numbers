## Steps
1. For each station id (sderot, route-232, observers-hill, reim-shelter, nova, tkuma, closing-drive) find a candidate point for the practical ARRIVAL spot (parking or safe stopping place), not only the landmark. For drive segments give the start point.
2. Use official sites, OpenStreetMap or Google Maps place pages, and amudanan.co.il. Record the source URL for every row.
3. Write lat and lng with 6 decimals, latitude first. Check that every point lies inside lat 31.2–31.7 and lng 34.3–34.8.
4. Add a clickable link https://www.google.com/maps?q=<lat>,<lng> per row.
5. Write review/C-03-coordinates.md with columns: station id, place description, lat, lng, maps link, source, confidence (high/medium/low), notes (parking, access, closures).
