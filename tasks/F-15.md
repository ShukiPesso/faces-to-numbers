## Goal
Each station page tells visitors what happened here, what to notice and whose story belongs to this place, with navigation, access notes, a moment of silence and previous/next.

## Steps
1. Resolve :slug with getStationBySlug; unknown → render NotFoundPage.
2. Header: t('tour.stationOf', { n: order, total }), h1 title, subtitle, DurationBadge, kind label, ShareButton.
3. If driverWarning → DriveBanner at the top.
4. Sections in this order: SectionHeading t('station.background') + background (Markdown); t('station.talkingPoints') + list; t('station.people') + PersonCard (primary) for each personIds entry; t('station.companions') + PersonCard (companion) for each companionPersonIds entry (omit the section if empty); SilenceMoment if silenceMoment; t('station.access') + accessNotes and, if lastVerified, t('station.lastVerified', { date }); NavLinks(location); t('station.sources') + SourceList if sources is not empty.
5. Mark-visited toggle (data-testid mark-visited) using markVisited / unmarkVisited with labels t('station.markVisited') / t('station.unmarkVisited').
6. Previous/next (data-testid prev-station / next-station) from getPrevStation / getNextStation. On the last station replace 'next' with t('station.end') and render tour.closing (Markdown).
7. On mobile render previous/next in the sticky bar specified in design/components/layout.md.
8. useDocumentTitle(station.title).
9. Tests: nova shows the silence moment; route-232 shows the driver warning and two PersonCards; reim-shelter shows 2 primary and 2 companion cards; closing-drive shows the end label and the closing text; an unknown slug shows NotFound.

## Do NOT
- Do not render navigation links for unverified locations (NavLinks handles it — do not bypass it).
- Do not reorder sections or add content that is not in the station data.
