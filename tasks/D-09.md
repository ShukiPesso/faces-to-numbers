# D-09 — Design QA of the built app and approval of visual baselines

| Agent | Model | Wave | Size | Status |
|---|---|---|---|---|
| design | opus | 6 · QA & launch | M | review |

**Depends on:** **T-07** (End-to-end — responsive layout and visual baselines (E2E-LAYOUT-01..04)), **F-13** (Home page), **F-14** (Tour overview page), **F-15** (Station page), **F-16** (Person page with reading depth and content-warning gate), **F-17** (About and Sources pages), **F-18** (Offline PWA — manifest, service worker, offline indicator, update prompt)  
**Unblocks:** H-06, L-01

## Goal
The built UI is checked against the approved design at all three breakpoints; visual baselines are approved or issues are filed.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `docs/05_DESIGN_BRIEF.md`
- `design/01-principles.md`
- `design/components/`
- `design/mockups/`
- `tests/e2e/layout.spec.ts-snapshots/`

## Owns files — you may create or modify ONLY these
- `design/qa/`
- `reports/D-09.md` (your report)

## Steps
1. Run the app (npm run build && npm run preview) and review every route at 390, 820 and 1440 px, plus read-aloud mode. Use the fixture build (npm run build:e2e && npm run preview:e2e) to see the NearbyBanner states and the warning gate.
2. Compare with design/mockups/shots and the component specs. Apply the checklist in docs/05_DESIGN_BRIEF.md §9 and the red flags in design/01-principles.md.
3. Review the Playwright visual baselines produced by T-07.
4. Save screenshots to design/qa/shots/ and write design/qa/<YYYY-MM-DD>.md: a table of issues (route, width, screenshot, expected, actual, severity blocker/major/minor) with blockers first, and the line 'Baselines approved: yes/no'.

## Do NOT
- Do not edit source code or tests — file issues only.

## Acceptance criteria — all must be true
- [ ] Every route is covered at three widths, with screenshots in design/qa/shots/ (at least 21 files).
- [ ] Every issue has a severity; blockers are listed first.

## How to verify
- `ls design/qa/shots | wc -l   (expect ≥ 21)`

## Definition of Done
Conventions §10 applies. Write `reports/D-09.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
