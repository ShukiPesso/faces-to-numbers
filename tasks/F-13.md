## Steps
1. G2 decision: keep the start button where the D-04 home mockup has it — after the intro and before 'לפני שיוצאים לדרך'.
2. Follow design/mockups/home.html. h1 = tour.title; subtitle; t('home.stationsCount', { n }) and t('home.totalDuration', { duration: formatMinutes(totalDurationMin) }).
3. Sections: intro (Markdown); t('home.messageTitle') + message (Markdown); t('home.safetyTitle') + safety list; t('home.howToTitle') + howTo list.
4. Primary button start-tour → '/station/<first slug>'. If getVisited() is not empty: resume-tour → the first station (by order) after the highest visited order, label t('home.resume', { n }); and reset-progress (t('home.resetProgress')) → resetProgress() and re-render.
5. useDocumentTitle(tour.title).
6. Test: intro and message text come from content; with visited [sderot, route-232, observers-hill] the resume button targets order 4; reset removes it.
