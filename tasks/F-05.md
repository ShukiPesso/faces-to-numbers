## Goal
Tailwind's theme is built only from the design tokens, fonts are self-hosted, and read-aloud mode works through a data attribute.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `design/tokens.json`
- `design/tokens.css`
- `design/02-tokens.md`
- `docs/02_ARCHITECTURE.md`

## Owns files — you may create or modify ONLY these
- `tailwind.config.ts`
- `src/styles/tokens.css`
- `src/styles/index.css`
- `src/styles/fonts.css`
- `reports/F-05.md` (your report)

## Steps
1. Copy design/tokens.css to src/styles/tokens.css unchanged.
2. tailwind.config.ts: REPLACE (not extend) colors, fontFamily, fontSize, spacing, borderRadius and boxShadow with entries that reference the tokens, e.g. colors: { bg: 'var(--color-bg)', ink: 'var(--color-ink)', … }. Keep breakpoints sm 640, md 768, lg 1024, xl 1280. Add maxWidth.measure = 'var(--measure)' and maxWidth.content = 'var(--content-max)'.
3. src/styles/fonts.css: import only the weights listed in design/02-tokens.md from @fontsource/assistant and @fontsource/frank-ruhl-libre (Hebrew and Latin subsets).
4. src/styles/index.css: import fonts.css and tokens.css, then the three @tailwind directives. Base layer: html background var(--color-bg), color var(--color-ink), font-family var(--font-body); body copy size and leading from tokens; :focus-visible outline 3px solid var(--color-focus) with offset; @media (prefers-reduced-motion: reduce) disable transitions and animations; html[data-read-aloud='true'] main uses --text-read and --leading-read.

## Do NOT
- No hard-coded colors or sizes outside tokens.css.
- Do not import whole font families (all weights).

## Acceptance criteria — all must be true
- [ ] npm run build succeeds and the total size of dist/assets/*.woff2 is ≤ 220 KB.
- [ ] npm run lint and npm run typecheck exit 0.

## How to verify
- `npm run build && du -cb dist/assets/*.woff2 | tail -1`
- `npm run lint && npm run typecheck`
