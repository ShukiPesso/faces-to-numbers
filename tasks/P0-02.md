## Steps
1. Copy contracts/content.schema.ts to src/content/schema.ts without any change.
2. Copy contracts/strings.he.ts to src/i18n/he.ts without any change.
3. Create src/lib/i18n.ts: import { he } from '@/i18n/he'; export type StringKey = keyof typeof he; export function t(key, params?) that replaces every {name} placeholder with String(params[name]) when params has that name, leaves unknown placeholders untouched, and in dev (import.meta.env.DEV) calls console.warn once per missing placeholder.
4. Write tests/unit/i18n.test.ts (UT-I18N-01). Compute expectations FROM he so later wording changes don't break tests: expect(t('home.resume', { n: 4 })).toBe(he['home.resume'].replace('{n}', '4')); expect(t('tour.stationOf', { n: 2, total: 7 })) equals the value with both replaced; a missing param leaves '{n}' in the output; a key without placeholders returns its value unchanged.
