## Steps
1. Resolve :id with getPersonById; unknown → NotFoundPage.
2. Header: h1 name + ' ' + honorific, subtitle, PhotoFrame, ShareButton, and a back link t('person.backToStation', { title }) to the first station in person.stationIds.
3. DepthTabs bound to the PrefsProvider depth.
4. Render by depth exactly per ADR-007: s30 → guideLevels.s30 in a read-aloud block with the hint t('depth.s30.hint'). m2 → opening; SectionHeading t('person.oct7') + oct7; QuoteBlock(quote). m5 → opening; oct7; SectionHeading t(pronoun === 'she' ? 'person.personality.she' : 'person.personality.he') + personality; t('person.past') + past; t('person.after') + after (if present); QuoteBlock(quote); QuoteBlock(altQuote) if present; t('person.guideNote') + guideNote if present; t('person.sources') + SourceList.
5. When oct7Sensitivity is 'graphic', wrap the oct7 section AND the s30 block in ContentWarningGate(personId, sensitivity).
6. useDocumentTitle(name).
7. Tests: switching depth renders the right sections; roni-eshel at m5 shows 'מי היא הייתה'; aner-shapira at m2 hides oct7 behind the gate until 'show'; raz-peretz at m5 shows the guideNote; an unknown id shows NotFound.
