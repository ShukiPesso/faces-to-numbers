## Goal
A calm, legible SVG schematic of the 7-segment route exists that a developer can turn into a component.

## Context
Not a geographic map — a schematic showing sequence and rough relative position. North is up. The Gaza border runs
along the west (left). Sequence: Sderot (north) → route 232 south past Mefalsim and Kfar Aza → observers' hill near
Nahal Oz / Sa'ad → Re'im junction shelter → Nova site (Re'im parking) → Tkuma (east, near Netivot) → the drive home.

## Steps
1. viewBox 0 0 360 640 (portrait). A thin dashed line on the west labelled 'גבול רצועת עזה'.
2. Draw the route as one continuous path. Drive segments dashed, stops solid. Numbered circle markers 1–7; the closing drive can be an arrow toward the east edge labelled 'הדרך הביתה'.
3. Each marker is a <g id="marker-<station-id>"> using exactly these ids: sderot, route-232, observers-hill, reim-shelter, nova, tkuma, closing-drive — containing the circle and a Hebrew <text> label with the station title from its file.
4. Use only token colors (write hex in the SVG, list the token name per color in route-map.md). No gradients, shadows, imagery, weapons or flames.
5. Optimize (no editor metadata). Include <title> and <desc> in Hebrew.
6. design/route-map.md: the marker id list, how 'current' and 'visited' look (stroke/fill change only), and the text alternative (the ordered station list).
7. Render a preview: npx playwright screenshot --viewport-size=390,700 file://$PWD/design/route-map.svg design/route-map-preview.png
