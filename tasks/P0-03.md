## Steps
1. vitest.config.ts: mergeConfig with the Vite config (call it with mode 'test'); environment node by default and jsdom for tests/component/** (environmentMatchGlobs); setupFiles ['tests/setup.ts']; include tests/{unit,component,integrity}/**/*.test.{ts,tsx}; coverage provider v8 with thresholds — src/lib/**: lines 100, branches 100; src/components/**: lines 80.
2. tests/setup.ts: import '@testing-library/jest-dom/vitest'; when document exists set document.documentElement lang='he' and dir='rtl'; afterEach clear localStorage and sessionStorage when they exist.
3. playwright.config.ts: testDir tests/e2e; two webServer entries — real: 'npm run build && npm run preview' on port 4173; fixture: 'npm run build:e2e && npm run preview:e2e' on port 4174; reuseExistingServer when not CI; timeout 180000 for servers.
4. Projects exactly as docs/04_TESTING_STRATEGY.md §2: mobile-chrome (devices['Pixel 7'], baseURL 4173, grepInvert /@fixture|@smoke/), mobile-safari (devices['iPhone 13'], 4173, grepInvert /@fixture|@smoke|@sw/), tablet (devices['iPad Mini'], 4173, grepInvert /@fixture|@smoke|@sw/), desktop (devices['Desktop Chrome'] with viewport 1440x900, 4173, grepInvert /@fixture|@smoke/), fixture-chrome (devices['Pixel 7'], 4174, grep /@fixture/), smoke (devices['Pixel 7'], baseURL process.env.LIVE_URL, grep /@smoke/). retries 2 on CI, workers 2 on CI, trace 'on-first-retry', reporter [['list'], ['html', { open: 'never' }]].
5. Create every helper in docs/04_TESTING_STRATEGY.md §3 with exactly those export names. geo.ts: FIXTURE_POINTS { atA, nearB, far } with the coordinates from §3; grantGeo(context, point) grants 'geolocation' and sets it; denyGeo(context) clears permissions; spyGeolocation(page) uses addInitScript to wrap navigator.geolocation.getCurrentPosition and count calls in window.__geoCalls.
6. offline.ts: waitForServiceWorker(page) uses expect.poll until navigator.serviceWorker.controller is not null (after awaiting navigator.serviceWorker.ready); goOffline/goOnline call context.setOffline.
7. layout.ts: expectNoHorizontalOverflow(page) asserts documentElement.scrollWidth <= clientWidth; expectTapTargets(page, min = 44) checks every visible button, a, [role=tab], input, select — width and height ≥ min — skipping elements inside [data-inline-text]; on failure list offending elements' text.
8. a11y.ts: expectNoSeriousA11yViolations(page) runs AxeBuilder and fails on impact serious or critical, printing ids and targets.
9. routes.ts: allRoutes() reads src/content/data/stations.json and src/content/data/people/*.json with fs at runtime and returns ['/', '/tour', '/about', '/sources', ...'/station/<slug>', ...'/person/<id>']; if the data folder does not exist yet return ['/'].
10. banned.ts: export BANNED_UI_WORDS = ['כל הכבוד', 'מעולה', 'הצלחתם', 'ניצחתם', 'צברתם', 'ניקוד', 'תג הישג', 'רמה הבאה'] and expectNoBannedWords(page) checking document.body.innerText.
11. tests/e2e/infra.spec.ts: one test that opens '/' and expects html[lang=he][dir=rtl] and a visible h1. tests/unit/infra.test.ts: one trivial passing test.

## Do NOT
- Do not write feature tests — only infrastructure and the two trivial tests.
- Do not use page.waitForTimeout anywhere.
- Do not edit vite.config.ts (owned by P0-01); use mergeConfig in vitest.config.ts.
- Do not commit installed browsers or test reports.
