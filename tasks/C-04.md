## Goal
Every visitor-facing text on the deployed site has been checked on screen against the source, at phone size.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `content-source/people/`
- `content-source/stations/`
- `content-source/tour.md`

## Owns files — you may create or modify ONLY these
- `review/C-04-rendered-proofread.md`
- `review/C-04-shots/`
- `reports/C-04.md` (your report)

## Steps
1. Open the live URL (from the latest O-03 deploy report) at a 390-px width (real phone or browser emulation).
2. Visit every route. On every person page read all three depths and open every warning gate.
3. Compare with content-source/ and the UI strings. Note: missing or reordered paragraphs, broken Markdown (stray ** or #), wrong gendered heading (Roni Eshel must show 'מי היא הייתה'), mixed-direction glitches (numbers, Latin text, URLs), truncated text.
4. Save a screenshot per issue in review/C-04-shots/ and write review/C-04-rendered-proofread.md (route, screenshot, issue, severity).

## Do NOT
- Report only; do not edit anything.

## Acceptance criteria — all must be true
- [ ] All routes and all people at all three depths are covered.

## How to verify
- Orchestrator reviews the report.

## Definition of Done
Conventions §10 applies. Write `reports/C-04.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
