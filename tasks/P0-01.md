## Steps
1. Write `20` to .nvmrc and use Node 20. Create a Vite + React + TypeScript project IN THE REPO ROOT without overwriting or deleting any existing file or folder.
2. Install runtime dependencies (latest within the major): react@18 react-dom@18 react-router-dom@6 zod@3 react-markdown@9 lucide-react @fontsource/assistant@5 @fontsource/frank-ruhl-libre@5.
3. Install dev dependencies: typescript@5 vite@5 @vitejs/plugin-react tailwindcss@3 postcss@8 autoprefixer@10 vite-plugin-pwa vitest@2 @vitest/coverage-v8@2 jsdom@25 @testing-library/react@16 @testing-library/user-event@14 @testing-library/jest-dom@6 @playwright/test@1 @axe-core/playwright@4 eslint@9 typescript-eslint@8 eslint-plugin-react-hooks@5 eslint-plugin-react-refresh prettier@3 gray-matter@4 tsx@4 @types/node.
4. Add every npm script from docs/02_ARCHITECTURE.md §7 exactly as written. Some point to files that later tasks create; that is expected.
5. tsconfig.json: strict true, noUncheckedIndexedAccess true, resolveJsonModule true, jsx react-jsx, target ES2022, module ESNext, moduleResolution bundler, paths '@/*' → 'src/*'; include src, tests, scripts.
6. index.html: <html lang="he" dir="rtl">; viewport meta 'width=device-width, initial-scale=1, viewport-fit=cover'; <title>פנים למספרים</title>; <meta name="theme-color" content="#FAF8F4">.
7. vite.config.ts: react plugin; base './'; resolve.alias '@' → src; resolve.alias '@content-data' → src/content/data.fixture.ts when mode === 'e2e', otherwise src/content/data.real.ts (use the defineConfig(({ mode }) => …) form). Do NOT add the PWA plugin (task F-18).
8. tailwind.config.ts: content ['./index.html', './src/**/*.{ts,tsx}']; theme left empty (task F-05 fills it). postcss.config.js with tailwindcss and autoprefixer.
9. eslint.config.js: flat config; typescript-eslint recommendedTypeChecked; react-hooks; react-refresh; rules: no-explicit-any error, no-console warn (allow warn, error); ignores dist, dist-e2e, coverage, playwright-report, test-results, spike.
10. src/main.tsx renders a placeholder: <main id="main"><h1>פנים למספרים</h1></main>. src/styles/index.css contains the three @tailwind directives and is imported by main.tsx.
11. .gitignore: node_modules, dist, dist-e2e, coverage, playwright-report, test-results, .env*, *.tar.gz. .prettierrc.json: { "printWidth": 100, "singleQuote": true }.
12. Create reports/.gitkeep, design/.gitkeep and review/.gitkeep.
