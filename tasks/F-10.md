## Steps
1. StationCard: props station, visited, current?. A Link to stationPath(slug) containing t('tour.stationOf', { n: order, total }), title, subtitle, DurationBadge, the kind label t('tour.kind.stop' | 'tour.kind.drive') and, when visited, t('tour.visited') with a check icon. data-testid station-card-<id>.
2. PersonCard: props person, variant ('primary' | 'companion'). Name + honorific, subtitle, opening (Markdown), and a link t('person.toStory', { name }) to personPath(id). Companion variant shows the label t('person.companion'). data-testid person-card-<id>.
3. ProgressStepper: props stations, visitedIds, currentId?. Ordered list; aria-current='step' on the current item; visited items show a check with an accessible name.
4. NavLinks: props location (GeoPoint | null). If location?.verified → two external Buttons, data-testid nav-waze and nav-google, hrefs from wazeUrl/googleMapsUrl, labels t('station.navigateWaze') / t('station.navigateGoogle'). Otherwise the text t('station.locationUnverified') with data-testid location-unverified and NO links.
5. DriveBanner: role='note', data-testid driver-warning, car icon and t('drive.warning').
6. tests/component/tour-cards.test.tsx: CT-CARD-01, CT-PCARD-01, CT-NAVL-01, CT-DRIVE-01, CT-STEP-01.
