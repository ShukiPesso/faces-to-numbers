## Steps
1. src/app/router.tsx: createHashRouter with the route table in docs/02_ARCHITECTURE.md §4; AppLayout as the root element with <Outlet/>; errorElement ErrorBoundary. Export the routes array too so tests can use createMemoryRouter.
2. src/pages/: stub components HomePage, TourPage, StationPage, PersonPage, AboutPage, SourcesPage that render only an h1 (from strings) and call useDocumentTitle — wave-4 tasks replace them. Build the real NotFoundPage (h1 notFound.title, notFound.body, link to '/' with notFound.home).
3. src/app/AppLayout.tsx: first element a skip link (data-testid skip-link) to #main; Header; SideNav (hidden below lg); <main id='main' tabIndex={-1}> with <Outlet/>; Footer; BottomNav (hidden at lg+). On route change scroll to top and focus <main>.
4. src/app/PrefsProvider.tsx: context with depth/setDepth and readAloud/setReadAloud backed by src/lib/storage.ts; when readAloud is true set document.documentElement.dataset.readAloud = 'true', otherwise delete it. Wrap the router in main.tsx.
5. src/app/ErrorBoundary.tsx: error element with error.title, error.body and a reload button (error.reload).
6. Header: app name linking home and an empty slot <div data-slot='header-actions'/> (F-08 adds the read-aloud toggle there). BottomNav (data-testid bottom-nav, nav aria-label from nav.label): home '/', tour '/tour', where-am-i '/tour?locate=1', about '/about' — icon + visible label per design. SideNav (data-testid side-nav): ordered list of stations from getStations() — order, title, visited check from getVisited() — plus the same four links. Footer: links to sources and about, and t('about.lastReview', { date }) from the tour.
7. src/hooks/useDocumentTitle.ts: sets document.title to `${title}${t('app.titleSuffix')}`.
8. tests/component/layout.test.tsx: render with createMemoryRouter at '/', '/station/nova' and '/nope'; assert the skip link is the first focusable element, landmarks exist (banner, navigation with a label, main, contentinfo), '/nope' shows NotFound, document.title is set.

## Do NOT

- Do not use BrowserRouter (hash routing only, ADR-002).
- No physical direction classes (ml mr pl pr left right text-left text-right).
