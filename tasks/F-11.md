## Steps
1. Convert design/route-map.svg into inline JSX in RouteMap.tsx (no external file fetch). Keep every <g id='marker-<station-id>'> and the geometry exactly.
2. Props stations, visitedIds, currentId?. Wrap each marker group in a Link to its station; apply visited and current styling only through the classes described in design/route-map.md.
3. The <svg> has role='img', aria-label t('tour.mapAlt') and data-testid route-map.
4. Test: 7 marker links with the correct hrefs; aria-label present; the visited class applied for visited ids.
