# H-06 — Final content and sensitivity sign-off

| Agent | Model | Wave | Size | Status |
|---|---|---|---|---|
| human | human | 6 · QA & launch | S | todo |

**Depends on:** **C-01** (Proofread the generated JSON against the Markdown sources), **C-02** (Verify every quote and key fact against the original articles), **C-04** (Proofread every page on the deployed site at phone size), **H-02** (Verify station coordinates and set them in the content source), **H-05** (Field test the whole route with the deployed app on two phones), **D-09** (Design QA of the built app and approval of visual baselines)  
**Unblocks:** L-01

## Goal
Shuki confirms that the content is accurate and the tone is right; all approved corrections are applied.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `review/C-02-verification.md`
- `review/C-01-conversion-proofread.md`
- `review/C-04-rendered-proofread.md`
- `review/H-05-field-test.md`
- `content-source/VERIFICATION.md`

## Owns files — you may create or modify ONLY these
- `review/H-06-signoff.md`
- `content-source/`
- `reports/H-06.md` (your report)

## Steps
1. Read review/C-02-verification.md and mark each proposed correction approve or reject.
2. The orchestrator applies approved corrections to content-source/ with a line each in CORRECTIONS.md, updates VERIFICATION.md (every 🔶 becomes ✅ or is removed), runs npm run content:build, and deploys.
3. Read the C-01, C-04, D-09 and H-05 reports and confirm every blocker is resolved.
4. Write review/H-06-signoff.md: 'I approve publication' (or not), the date, and any conditions.

## Do NOT
- Do not approve while any 🔶 remains in content-source/VERIFICATION.md.

## Acceptance criteria — all must be true
- [ ] content-source/VERIFICATION.md contains no 🔶.
- [ ] The sign-off file is written and dated.

## How to verify
- `grep -c '🔶' content-source/VERIFICATION.md   (expect 0)`

## Definition of Done
Conventions §10 applies. Write `reports/H-06.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
