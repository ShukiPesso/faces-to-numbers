## Goal
A human-readable confirmation exists that the generated JSON says exactly what the Markdown says, field by field, for all 9 people, 7 stations and the tour.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `content-source/README.md`
- `content-source/people/`
- `content-source/stations/`
- `content-source/tour.md`
- `src/content/data/`

## Owns files — you may create or modify ONLY these
- `review/C-01-conversion-proofread.md`
- `reports/C-01.md` (your report)

## Steps
1. For each source file open the matching JSON and compare every field listed in content-source/README.md: front matter → fields, sections → fields, guideLevels, quote/altQuote, sources.
2. Check especially: Hebrew punctuation (״ ׳ „ ” – —) preserved; ** bold markers preserved; paragraph breaks preserved; nothing truncated; URLs identical.
3. Write review/C-01-conversion-proofread.md: one section per file with 'OK' or a list of differences (field, expected, actual).

## Do NOT
- Do not edit JSON or Markdown — report only.

## Acceptance criteria — all must be true
- [ ] The report covers 17 files (9 people, 7 stations, tour) with an explicit OK or diff for each.

## How to verify
- Orchestrator checks that 17 files are listed.

## Definition of Done
Conventions §10 applies. Write `reports/C-01.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
