## Steps
1. Copy design/brand files into public/: icons into public/icons/, favicon.svg and og-image (renamed og-image.png) to public/.
2. vite.config.ts: add VitePWA with registerType 'prompt', injectRegister false, manifest { name 'פנים למספרים — סיור עצמאי בעוטף עזה', short_name 'פנים למספרים', lang 'he', dir 'rtl', start_url './#/', scope './', display 'standalone', background_color and theme_color = the hex values of --color-bg and --color-primary from design/tokens.json, icons 192, 512 and a 512 maskable }, workbox { globPatterns ['**/*.{js,css,html,svg,png,webp,woff2,json,webmanifest}'], navigateFallback 'index.html', cleanupOutdatedCaches true, maximumFileSizeToCacheInBytes 2500000 }. Keep the existing '@content-data' and '@' aliases.
3. src/pwa.ts: registerSW from 'virtual:pwa-register' with onNeedRefresh → state for UpdatePrompt, onOfflineReady → state for OfflineIndicator (show the ready message once, hide after 6 seconds). Export a small store/hook the components subscribe to.
4. src/hooks/useOnlineStatus.ts: navigator.onLine plus online/offline events.
5. OfflineIndicator (data-testid offline-indicator, aria-live polite): offline → t('offline.now'); first offline-ready → t('offline.ready').
6. UpdatePrompt (data-testid update-prompt): t('update.available') and a button t('update.reload') that calls updateSW(true). Never reload automatically.
7. AppLayout: render OfflineIndicator and UpdatePrompt directly above <main>. Change nothing else.
8. index.html: favicon, apple-touch-icon, og:title, og:description (the tagline), og:image ./og-image.png, og:locale he_IL, theme-color.
9. tests/component/pwa-ui.test.tsx: OfflineIndicator reacts to offline/online events; UpdatePrompt calls the update function on click (mock 'virtual:pwa-register').
