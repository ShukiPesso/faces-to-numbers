Graphic passages sit behind a calm, optional gate, and a moment of silence can be started deliberately and ends quietly.

## Steps
1. ContentWarningGate: props personId, sensitivity, children. 'standard' → render children. 'graphic' → if isGateOpened(personId) render children; otherwise render a calm panel (data-testid warning-gate) with t('warning.title'), t('warning.body') and two buttons: warning-show → openGate(personId), render children and move focus to the first element of the revealed content; warning-skip → show t('warning.skipped') with the show button still available, and move focus to the next element after the gate.
2. SilenceMoment: props seconds and prompt. idle: t('silence.title'), the prompt, and a start button (data-testid silence-start, label t('silence.start', { seconds })). running (decision 2026-10-11, Shuki: NO running countdown): a calm static panel (data-testid silence-timer) showing t('silence.title') and the prompt, with a stop button t('silence.stop'); nothing on screen changes while it runs; one setTimeout of `seconds` ends it; announce only start and end (aria-live). ended: t('silence.ended'). The key 'silence.remaining' stays in he.ts but is NOT rendered. No sound, no vibration; at most a slow opacity change, none under prefers-reduced-motion. Clear the timeout on unmount.
3. Tests CT-GATE-01 and CT-SILENCE-01 (use vi.useFakeTimers).

## Do NOT
- Never start the silence timer automatically. Never play a sound or vibrate.
- Do not hide content permanently — the visitor can always choose to show it.
