# D-06 — Icon list (Lucide) with RTL rules

| Agent | Model | Wave | Size | Status |

**Depends on:** **D-01** (Design principles and tone)  
**Unblocks:** D-04, F-06, F-07

## Goal
A short, consistent icon table exists so developers never choose icons themselves.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `docs/05_DESIGN_BRIEF.md`
- `design/01-principles.md`

## Owns files — you may create or modify ONLY these
- `design/icons.md`
- `reports/D-06.md` (your report)

## Steps
1. List every icon the app needs: home, route/map, where-am-i/location, about/info, sources, next, previous, external navigation, visited/check, warning, silence, read-aloud, share, offline, update/refresh, duration/clock, drive/car.
2. For each give: the lucide-react component name (verify it exists in the installed package), where it is used, size token, stroke width, and whether it must mirror in RTL (all directional arrows and chevrons).
3. State the rule: every action icon appears with a visible text label.

## Do NOT
- No brand logos (Waze, Google) — use a neutral navigation icon plus text.
- No icons depicting weapons, fire, blood or violence.

## Acceptance criteria — all must be true
- [ ] design/icons.md has a row for every need above, each with an existing lucide-react name and a mirror yes/no column.

## How to verify
- `node -e "const l=require('lucide-react');const names=['MapPin','ChevronLeft'];for(const n of names){if(!l[n])throw new Error(n)}console.log('ok')"   (extend names with every icon in the table)`

Conventions §10 applies. Write `reports/D-06.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
