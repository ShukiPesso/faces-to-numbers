## Goal
Once the site was opened with reception, the whole tour works with no reception at all — the core promise for a car driving along the Gaza border.

## Context
Service workers only work in Chromium projects in Playwright; tag these tests @sw. Use the production
preview build (npm run build && npm run preview), never the dev server — vite-plugin-pwa does not
register a service worker in dev by default.

## Steps
1. E2E-OFF-01 (@sw, mobile-chrome and desktop): goto '/' → waitForServiceWorker(page) → wait until navigator.serviceWorker.controller is set (reload once if needed) → goOffline(context) → for every route in allRoutes(): navigate with the in-app links or page.goto, assert the h1 is visible and the main content is not empty; offline-indicator visible. goOnline at the end.
2. E2E-OFF-02 (@sw, mobile-chrome): after the SW is controlling → goOffline → page.reload() → the app shell and a station page load from cache.
3. E2E-PWA-01 (@sw, mobile-chrome): fetch the manifest linked from <link rel=manifest>; assert name and short_name non-empty, lang 'he', dir 'rtl', display 'standalone', start_url present, icons include 192×192 and 512×512 and one with purpose containing 'maskable'; navigator.serviceWorker.getRegistration() is defined.
4. If a route fails offline, report which asset was missing (use page.on('requestfailed') to list URLs).

## Do NOT
