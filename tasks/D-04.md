## Steps
1. Create self-contained HTML files in design/mockups/ that link ../tokens.css and contain any extra CSS inline (no external requests; system Hebrew fonts are acceptable fallbacks in mockups): home.html, tour.html, station-stop.html (reim-shelter), station-drive.html (route-232), person-s30.html, person-m2.html (aner-shapira, warning gate closed), person-m5.html (roni-eshel), about.html, sources.html, not-found.html, states.html (offline banner, update prompt, NearbyBanner 7 states, silence running, read-aloud mode).

3. Each mockup is responsive for base (360–767), md (768–1023) and lg (≥ 1024) as in docs/05_DESIGN_BRIEF.md §5, using only tokens.
4. Screenshot every file at 390×844, 820×1180 and 1440×900 into design/mockups/shots/<page>-<width>.png (command in docs/05_DESIGN_BRIEF.md §8).
5. Write design/mockups/README.md: the list of pages and states, what to look at, open questions for Shuki, and an 'Approved by Shuki on: ____' line.
