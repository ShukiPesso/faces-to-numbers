# D-02 — Design tokens with a contrast table

**Depends on:** **D-01** (Design principles and tone)  
**Unblocks:** D-03, D-05, D-08, F-05

## Goal
A complete, contrast-checked token set (color, type, space, radius, shadow, motion, layout) exists as JSON and as CSS custom properties.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `docs/05_DESIGN_BRIEF.md`
- `design/01-principles.md`
- `docs/02_ARCHITECTURE.md`

## Owns files — you may create or modify ONLY these
- `design/tokens.json`
- `design/tokens.css`
- `design/02-tokens.md`
- `reports/D-02.md` (your report)

## Steps
1. Start from the palette in docs/05_DESIGN_BRIEF.md §4. Change values only to meet contrast: body text on background ≥ 7:1; secondary text and UI ≥ 4.5:1; focus ring ≥ 3:1 against adjacent colors.
2. Color tokens, exactly these names: --color-bg, --color-surface, --color-border, --color-ink, --color-ink-muted, --color-primary, --color-primary-ink, --color-accent, --color-accent-soft, --color-gold, --color-gold-soft, --color-warning-bg, --color-focus.
3. Fonts: only the installed @fontsource families — Assistant (UI/body) and Frank Ruhl Libre (headings/quotes). Choose at most 4 weights in total and list them. Tokens --font-body and --font-display with Hebrew-capable fallbacks.
4. Type scale --text-xs … --text-3xl with matching --leading-* for base and for md+ (body ≥ 18px at base). Read-aloud tokens: --text-read ≥ 22px, --leading-read ≥ 1.7.
5. Space --space-1 … --space-12 (4px base); --radius-sm, --radius-md, --radius-lg; one subtle --shadow-card; motion --duration-fast 150ms, --duration-base 200ms, --ease-standard; layout --measure (about 68ch), --content-max 720px, --tap-min 44px.
6. Write design/tokens.json (same names and values) and design/tokens.css (a :root block plus an html[data-read-aloud='true'] block overriding body text size and leading).
7. design/02-tokens.md: the chosen font weights, and a contrast table of every text/background pair you intend to use, with the computed WCAG ratio and pass/fail. Show how you computed it (formula or script).

## Do NOT
- Do not use pure #000 on pure #FFF; keep the warm paper look.
- Do not add a dark theme in MVP.
- Do not reference fonts that are not installed.

## Acceptance criteria — all must be true
- [ ] Every token name listed above exists in both tokens.json and tokens.css.
- [ ] The contrast table shows body text ≥ 7:1 and all other text ≥ 4.5:1, all marked pass.
- [ ] The read-aloud override block exists.

## How to verify
- `node -e "const t=require('./design/tokens.json');console.log(Object.keys(t).length+' tokens')"`
- Orchestrator re-checks three contrast ratios with an online WCAG checker.
