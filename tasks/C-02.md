# C-02 — Verify every quote and key fact against the original articles

| Agent | Model | Wave | Size | Status |
|---|---|---|---|---|
| content | fable | 1 · Parallel lanes start | L | done |

**Depends on:** none — can start immediately  
**Unblocks:** C-05, H-06

## Goal
Every 🔶 item in content-source/VERIFICATION.md is checked word-for-word against the original Hebrew article, with an exact proposed correction wherever it differs.

## Context
The content was first researched from article summaries. Several quotes then turned out to be paraphrased or
misattributed (see CORRECTIONS.md). This is the only content task allowed to browse the web — and it still must not
edit content-source/. It produces a report; Shuki approves; the orchestrator applies the approved changes.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `content-source/VERIFICATION.md`
- `content-source/CORRECTIONS.md`
- `content-source/people/`
- `content-source/stations/`

## Owns files — you may create or modify ONLY these
- `review/C-02-verification.md`
- `reports/C-02.md` (your report)

## Steps
1. For every 🔶 row (Q*, F*, S*) open the listed source. If the link is dead, find the same article on the same outlet and record the working URL.
2. Copy the exact original sentence(s) into the report next to our text.
3. Classify each row: MATCH (identical apart from punctuation or quotation marks), MINOR (wording differs, meaning the same — propose a verbatim replacement), MISMATCH (meaning or attribution differs — propose a correction), NOT FOUND (cannot confirm — propose removal).
4. F11 (Raz Peretz's six fallen comrades): find each on izkor.gov.il; record the exact Hebrew full name with rank and the Izkor URL.
5. S7 (Tkuma hours): find the most recent official or news information and its date.
6. Write review/C-02-verification.md: one table per section (quotes, people facts, station facts) with columns ID, our text, original text, source URL + date accessed, classification, proposed replacement (exact Hebrew).

## Do NOT
- Do not edit content-source/ or src/ — report only.
- Do not use AI summaries, translations or search-result snippets as evidence — only the article text itself.
- Do not translate: if the original is English, quote the English and say so.
- Do not propose facts that are not in the original sources.

## Acceptance criteria — all must be true
- [ ] Every 🔶 row in content-source/VERIFICATION.md appears in the report with a classification.
- [ ] Every MINOR or MISMATCH row has the original text and an exact proposed replacement.
- [ ] F11 lists six names with Izkor URLs, or explains exactly why not.

## How to verify
- Orchestrator opens 5 random source URLs and compares.

## Definition of Done
Conventions §10 applies. Write `reports/C-02.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
