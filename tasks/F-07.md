## Steps
1. Button: variants primary | secondary | quiet | link; renders <a> when href is given, otherwise <button type='button'>; minimum size var(--tap-min); visible focus ring; external prop adds target _blank and rel 'noopener noreferrer'.
2. SectionHeading: props level (2 | 3), id?, children.
3. DurationBadge: props minutes; text from formatMinutes; clock icon from design/icons.md.
4. Markdown: react-markdown WITHOUT rehype-raw; component overrides for p, strong, ul, ol, li, a (external links get target _blank, rel 'noopener noreferrer' and a visually hidden t('common.externalLink')); the wrapper element has the attribute data-inline-text.
5. QuoteBlock: props quote { text, by }; markup <figure><blockquote>„{text}”</blockquote><figcaption>— {by}</figcaption></figure> styled per spec.
6. PhotoFrame: props photo (Photo), name. status pending → a placeholder box with t('photo.pending') and data-testid photo-placeholder and NO <img>. status cleared → <img src={photo.src} alt={photo.alt} loading='lazy'> and t('photo.credit', { credit }). Never read photo.referenceUrl.
7. SourceList: props sources (Source[]); each item: the title as an external link plus the host name inside <bdi dir='ltr'>.
8. ShareButton (data-testid share-button): if navigator.share exists call it with { title: document.title, url: location.href }; otherwise await navigator.clipboard.writeText(location.href) and show t('share.copied') in an aria-live='polite' region for 3 seconds; on any error show t('share.failed').
9. tests/component/primitives.test.tsx: CT-MD-01, CT-QUOTE-01, CT-PHOTO-01, CT-SRC-01, and both ShareButton branches with a mocked navigator.

- Do not use photo.referenceUrl anywhere.
- Do not hard-code Hebrew strings — use t().
