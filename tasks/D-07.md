# D-07 — Microcopy review of all UI strings (values only)

| Agent | Model | Wave | Size | Status |
|---|---|---|---|---|
| design | opus | 2 · Building blocks | M | todo |

**Depends on:** **D-01** (Design principles and tone), **P0-02** (Copy the frozen contracts into src and implement t())  
**Unblocks:** F-09, T-02

## Goal
Every UI string is calm, clear and consistent — changed by value only, never by key.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `contracts/strings.he.ts`
- `design/01-principles.md`
- `content-source/tour.md`

## Owns files — you may create or modify ONLY these
- `design/microcopy.md`
- `src/i18n/he.ts`
- `reports/D-07.md` (your report)

## Steps
1. Review every value in src/i18n/he.ts against Conventions §1.4 and §1.8 and design/01-principles.md. Focus on warning.*, silence.*, nearby.*, drive.warning, offline.*, update.*, error.*, notFound.*.
2. Improve wording where needed: clarity, plural address, gender-neutral phrasing, consistent infinitive verbs on buttons (להציג, לדלג, לעדכן).
3. Keep every {placeholder} that exists in the original value.
4. Write design/microcopy.md: a table of every changed key (old value, new value, reason) and a 10-rule style guide.

## Do NOT
- Do not add, remove or rename keys.
- No '!', no emoji, no celebratory words, no slang.
- Do not touch content about people or stations.

## Acceptance criteria — all must be true
- [ ] The key set of src/i18n/he.ts is identical to contracts/strings.he.ts.
- [ ] No value contains '!' or an emoji; every original placeholder is still present.
- [ ] npm run typecheck and tests/unit/i18n.test.ts pass.

## How to verify
- `npx tsx -e "import {he as a} from './contracts/strings.he.ts'; import {he as b} from './src/i18n/he.ts'; if (Object.keys(a).sort().join() !== Object.keys(b).sort().join()) throw new Error('keys differ'); console.log('keys identical')"`
- `npm run typecheck && npm test -- tests/unit/i18n.test.ts`

## Definition of Done
Conventions §10 applies. Write `reports/D-07.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
