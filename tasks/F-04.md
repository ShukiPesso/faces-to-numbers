## Steps
1. formatMinutes(min): throw RangeError if min is not an integer, is NaN, or is < 1. h = Math.floor(min / 60), m = min % 60. Minutes alone (h = 0): 1 → 'דקה', otherwise `${m} דקות`. Hours part: 1 → 'שעה', 2 → 'שעתיים', ≥ 3 → `${h} שעות`. With hours: m = 0 → hours part; m = 30 → hours part + ' וחצי'; m = 1 → hours part + ' ודקה'; otherwise hours part + ` ו-${m} דקות`. Every row of the table in docs/02_ARCHITECTURE.md §6 must match.
2. formatDistance(m) exactly per the doc comment in docs/02_ARCHITECTURE.md §6.
3. storage.ts per the table in §6 with a private helper safe<T>(fn: () => T, fallback: T): T using try/catch. Store arrays/booleans as JSON. On read, validate the shape (array of strings; 's30' | 'm2' | 'm5'; boolean); on invalid data return the default AND overwrite the key with the default. Gates use sessionStorage; everything else localStorage.
4. tests/unit/format.test.ts: UT-FMT-01..03 (every table row, every error case, every formatDistance case).
5. tests/unit/storage.test.ts: put `// @vitest-environment jsdom` on the first line; UT-STO-01..06; simulate failures with vi.spyOn(Storage.prototype, 'getItem') / 'setItem' throwing.
