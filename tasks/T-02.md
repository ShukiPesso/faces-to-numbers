## Goal
Static scans make the most important rules of the project impossible to break silently: no press photos, no exclamation or gamification words, no swapped coordinates, no missing strings, no left/right CSS.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `docs/04_TESTING_STRATEGY.md`
- `src/i18n/he.ts`
- `tests/e2e/helpers/banned.ts`
- `src/content/data/`

## Owns files — you may create or modify ONLY these
- `tests/integrity/repo-scans.test.ts`
- `reports/T-02.md` (your report)

## Steps
1. Use a small recursive fs.readdirSync helper to list files (no new dependency); read with fs. Put each check in its own test named with its ID.
2. CI-06: the string 'referenceUrl' does not occur in any file under src/components/ or src/pages/; and for every person JSON with photo.status 'cleared', the file public + photo.src exists.
3. CI-07: import { he } from src/i18n/he.ts; no value contains '!' or an emoji (regex /\p{Extended_Pictographic}/u) or any word from BANNED_UI_WORDS (import it from tests/e2e/helpers/banned.ts). Report every offending key, not only the first.
4. CI-08: every non-null station location has 31.2 ≤ lat ≤ 31.7 and 34.3 ≤ lng ≤ 34.8 (catches swapped lat/lng).
5. CI-09: scan src/**/*.{ts,tsx} with /\bt\(\s*['"]([a-zA-Z0-9_.]+)['"]/g; every captured key exists in he. Also list keys in he that are never used — print them as a console.warn, do not fail.
6. CI-10: scan src/**/*.{ts,tsx,css} for physical-direction Tailwind classes: /\b(ml|mr|pl|pr|left|right|border-l|border-r|rounded-l|rounded-r|text-left|text-right)-/ inside className strings or @apply. Fail with file:line list. (Logical classes ms-, me-, ps-, pe-, start-, end-, text-start, text-end are the correct ones.)
7. Negative self-check for each scan: run the same matcher function on a small inline bad string and expect it to report it.

## Do NOT
- Do not add exceptions to make a scan pass. A hit is a finding for the owner of that file — report it.

## Acceptance criteria — all must be true
- [ ] CI-06..CI-10 pass on the current repo, each with a negative self-check.
