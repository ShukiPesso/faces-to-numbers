## Steps
1. data.real.ts: export const raw: RawContentSet built from ./data/tour.json, ./data/stations.json and import.meta.glob('./data/people/*.json', { eager: true, import: 'default' }).
2. data.fixture.ts: the same shape from ./fixtures/tour.json, ./fixtures/stations.json and ./fixtures/people/*.json.
3. Create the fixture set exactly as docs/04_TESTING_STRATEGY.md §3: stations test-a, test-b, test-c and people test-person-1..3, with FICTIONAL text ('דמות בדיקה 1', 'תחנת בדיקה א' …), verified locations for test-a and test-b (verifiedBy 'fixture', verifiedAt '2026-01-01'), sourceFile values 'content-source/people/00_test-person-N.md' / 'content-source/stations/00_test-x.md'. Every fixture object must pass the zod schemas.
4. index.ts: import { raw } from '@content-data'; implement validateContent(raw) per docs/02_ARCHITECTURE.md §6 — zod parsing plus every cross-reference rule listed there; collect ALL problems and throw one ContentError whose message lists them all. Validate once at module load, cache the result, and export the getters from §6.
5. tests/unit/content-loader.test.ts: on real content — 7 stations, 9 people; getStationBySlug('nova'); getPeopleForStation('reim-shelter') returns 2 primary and 2 companions; next/prev at both ends return undefined. validateContent must fail with a clear message for: duplicate id, unknown referenced person, one-directional reference, non-contiguous order (build bad sets by deep-cloning the real data).
6. tests/integrity/schema.test.ts: CI-01 (every JSON file parses with its schema) and CI-02 (validateContent passes) — for the real set and for the fixture set.

## Do NOT
- Do not edit src/content/data/ (generated) or content-source/.
- Never use real people's names in fixtures.
- No runtime fetching of content — static imports only.

## Acceptance criteria — all must be true
- [ ] content-loader and schema tests pass; validateContent reports all problems at once.
- [ ] npm run build succeeds and the production bundle contains no fixture text; npm run build:e2e contains it.

## How to verify
- `npm test -- tests/unit/content-loader.test.ts tests/integrity/schema.test.ts`
- `npm run build && ! grep -rq 'דמות בדיקה' dist && npm run build:e2e && grep -rq 'דמות בדיקה' dist-e2e && echo bundles-ok`
