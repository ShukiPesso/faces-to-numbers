**Unblocks:** O-03, T-11

## Goal
Within a minute of each deploy we know the live site opens, shows content and installs its service worker.

## Read-only inputs
- docs/03_CONVENTIONS.md (always)
- `docs/04_TESTING_STRATEGY.md`
- `playwright.config.ts`

## Owns files — you may create or modify ONLY these
- `tests/e2e/smoke.spec.ts`
- `reports/T-10.md` (your report)

## Steps
1. All tests tagged @smoke; they run only in the 'smoke' project whose baseURL is process.env.LIVE_URL. If LIVE_URL is not set the whole file is skipped with test.skip(!process.env.LIVE_URL, 'LIVE_URL not set') — this is the one approved skip.
2. E2E-SMOKE-01: response of page.goto('/') has status 200; h1 visible; html dir rtl.
3. E2E-SMOKE-02: open the tour, click the first station card → its h1 is visible.
4. E2E-SMOKE-03: navigator.serviceWorker.ready resolves within 15 s; collect console messages of type 'error' during the whole file and expect none.
5. Do not depend on any specific person or text; content changes must not break smoke tests.

## Do NOT
- No writes, no form posts — the smoke test must be safe to run against production at any time.

## Acceptance criteria — all must be true
- [ ] With LIVE_URL pointing at `npm run preview` (http://localhost:4173) all three pass; without LIVE_URL the file is skipped.

## How to verify
- `npm run build && (npm run preview &) && sleep 3 && LIVE_URL=http://localhost:4173 npx playwright test --project=smoke`

Conventions §10 applies. Write `reports/T-10.md` from `templates/REPORT_TEMPLATE.md`. If anything is unclear or missing: stop, set status BLOCKED in the report, and ask (Conventions §11).
